# Palco Player v1.2.0 — Estável

Data: 20/10/2026

## Estado

**Estável / validado pelo usuário em uso real no celular.**

O usuário confirmou nesta conversa que a melhoria de repetição funcionou. Essa confirmação complementa os testes automatizados já documentados em [docs/testes-v1.2.md](../docs/testes-v1.2.md); não representa um novo ensaio automatizado no dispositivo.

## Mudanças em relação à v1.1

- Botão separado para repetir somente a música selecionada continuamente até desativação.
- Botão separado para repetir a playlist inteira.
- Modos exclusivos entre si; é possível manter ambos desativados.
- Ajuste para o modo aleatório encerrar ao finalizar a rodada quando a repetição estiver desligada.
- Interface responsiva e controles anteriores preservados.
